# راهنمای نصب و راه‌اندازی Persian AI Assistant

این پروژه از دو بخش تشکیل شده است:

1. **AI Server:** سرور پردازش هوش مصنوعی که روی VPS و با Docker اجرا می‌شود.
2. **WordPress Plugin:** افزونه وردپرس که روی سایت نصب می‌شود و با سرور ارتباط برقرار می‌کند.

ابتدا سرور هوش مصنوعی را راه‌اندازی کنید و سپس افزونه را نصب و به آن متصل کنید.

---

# بخش اول: نصب و راه‌اندازی سرور

## ۱. پیش‌نیازها

قبل از شروع، موارد زیر را آماده کنید:

- یک VPS با سیستم‌عامل Ubuntu 22.04 یا بالاتر
- دسترسی SSH به سرور و مجوز اجرای دستورات `sudo`
- یک دامنه یا زیردامنه برای سرور هوش مصنوعی (مثلاً `ai.example.com`)
- یک API Key معتبر از OpenAI یا سرویس سازگار با API آن
- آدرس عمومی وب‌سایت وردپرسی (مثلاً `https://example.com`)

### تنظیم DNS دامنه

در پنل مدیریت دامنه، یک رکورد از نوع A ایجاد کنید:

| Type | Name | Value |
|---|---|---|
| A | `ai` | `SERVER_IP` |

به‌جای `SERVER_IP`، آدرس IP سرور خود را قرار دهید.

پس از ثبت رکورد، انتشار DNS را بررسی کنید:

```bash
nslookup ai.example.com
```

خروجی باید IP سرور شما را نمایش دهد.

> تا زمانی که دامنه به IP صحیح سرور اشاره نکند، صدور گواهی HTTPS با مشکل مواجه خواهد شد.

## ۲. اتصال به سرور

از طریق ترمینال سیستم خود به VPS متصل شوید:

```bash
ssh root@SERVER_IP
```

اگر از کاربر دیگری استفاده می‌کنید:

```bash
ssh username@SERVER_IP
```

سپس بسته‌های سیستم را به‌روزرسانی کنید:

```bash
sudo apt update && sudo apt upgrade -y
```

## ۳. نصب Docker

برای نصب Docker، دستور زیر را اجرا کنید:

```bash
curl -fsSL https://get.docker.com | sh
```

سپس سرویس Docker را فعال کنید:

```bash
sudo systemctl enable --now docker
```

نصب Docker و Docker Compose را بررسی کنید:

```bash
docker --version
docker compose version
```

هر دو دستور باید نسخه نصب‌شده را نمایش دهند.

## ۴. باز کردن پورت‌های موردنیاز

برای دسترسی عمومی به سرور، پورت‌های زیر باید باز باشند:

| Port | Protocol | کاربرد |
|---|---|---|
| 80 | TCP | دریافت درخواست HTTP و صدور گواهی SSL |
| 443 | TCP | ارتباط امن HTTPS |

اگر از UFW استفاده می‌کنید:

```bash
sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
```

سپس فایروال را فعال کنید:

```bash
sudo ufw enable
```

وضعیت فایروال را بررسی کنید:

```bash
sudo ufw status
```

همچنین در صورت وجود Firewall در پنل ارائه‌دهنده VPS، پورت‌های مذکور را از آنجا نیز باز کنید.

> قبل از فعال‌سازی UFW مطمئن شوید دسترسی SSH مجاز است تا اتصال شما به سرور قطع نشود.

## ۵. انتقال پروژه به سرور

پوشه `ai-server` را به سرور منتقل کنید.

برای مثال، از سیستم خودتان اجرا کنید:

```bash
scp -r ./ai-server root@SERVER_IP:/opt/ai-server
```

سپس وارد پوشه پروژه شوید:

```bash
cd /opt/ai-server
```

مطمئن شوید فایل‌های اصلی پروژه در محل صحیح قرار دارند:

```bash
ls -la
```

## ۶. ساخت فایل تنظیمات محیطی

اسکریپت راه‌اندازی اولیه را اجرا کنید:

```bash
bash deploy/init-env.sh
```

این اسکریپت اطلاعات موردنیاز را از شما دریافت می‌کند:

- دامنه سرور هوش مصنوعی، مانند `ai.example.com`
- آدرس وب‌سایت وردپرسی، مانند `https://example.com`
- کلید API سرویس OpenAI

سایر مقادیر موردنیاز به‌صورت خودکار تولید و تنظیم می‌شوند.

در پایان، دو مقدار زیر در خروجی نمایش داده می‌شوند:

```text
PWC_API_URL
PWC_API_SECRET
```

**این دو مقدار را ذخیره کنید. در بخش نصب افزونه به آن‌ها نیاز خواهید داشت.**

فایل `.env` نیز در مسیر اصلی `ai-server` ساخته می‌شود.

> فایل `.env` حاوی اطلاعات محرمانه است. آن را در GitHub منتشر نکنید و در اختیار افراد دیگر قرار ندهید.

## ۷. اجرای سرور

برای ساخت و اجرای سرویس‌ها دستور زیر را اجرا کنید:

```bash
docker compose up -d --build
```

در اولین اجرا، Docker تصاویر موردنیاز را دریافت کرده و سرویس‌های پروژه را راه‌اندازی می‌کند.

برای بررسی وضعیت سرویس‌ها:

```bash
docker compose ps
```

سرویس‌ها باید در وضعیت `running` یا `healthy` باشند.

## ۸. بررسی سلامت سرور

برای بررسی سلامت API، درخواست زیر را ارسال کنید:

```bash
curl https://ai.example.com/health
```

در صورت راه‌اندازی صحیح، خروجی باید مشابه زیر باشد:

```json
{
  "status": "ok"
}
```

همچنین می‌توانید لاگ سرویس API را بررسی کنید:

```bash
docker compose logs -f api
```

برای خروج از نمایش زنده لاگ‌ها، کلیدهای `Ctrl + C` را فشار دهید. این کار سرویس را متوقف نمی‌کند.

> در اولین اجرا ممکن است صدور گواهی SSL چند ثانیه زمان ببرد. اگر گواهی صادر نشد، تنظیمات DNS و دسترسی پورت‌های 80 و 443 را بررسی کنید.

با موفقیت این مرحله، سرور هوش مصنوعی آماده اتصال به افزونه وردپرس است.

# بخش دوم: نصب و راه‌اندازی افزونه وردپرس

## ۱. نصب افزونه

وارد پیشخوان وردپرس شوید.

از منوی مدیریت به مسیر زیر بروید:

`افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه`

فایل زیر را انتخاب کنید:

```text
release/persian-wp-chatbot-1.0.0.zip
```

سپس:

1. روی «نصب» کلیک کنید.
2. منتظر تکمیل نصب بمانید.
3. روی «فعال‌سازی افزونه» کلیک کنید.

پس از فعال‌سازی، بخش مدیریت چت‌بات در پیشخوان وردپرس در دسترس خواهد بود.

## ۲. تنظیم اطلاعات اتصال به سرور

برای برقراری ارتباط امن، باید اطلاعات اتصال تولیدشده در مرحله ۶ نصب سرور را در فایل `wp-config.php` وردپرس قرار دهید.

فایل `wp-config.php` در مسیر اصلی نصب وردپرس قرار دارد.

این دو خط را قبل از عبارت زیر اضافه کنید:

```php
/* That's all, stop editing! Happy publishing. */
```

کد:

```php
define( 'PWC_API_URL', 'https://ai.example.com' );
define( 'PWC_API_SECRET', 'YOUR_API_SECRET' );
```

مقادیر را با اطلاعات واقعی سرور جایگزین کنید:

- `PWC_API_URL`: آدرس سرور هوش مصنوعی که در مرحله نصب دریافت کردید.
- `PWC_API_SECRET`: کلید محرمانه تولیدشده توسط اسکریپت راه‌اندازی سرور.

نمونه:

```php
define( 'PWC_API_URL', 'https://ai.example.com' );
define( 'PWC_API_SECRET', 'your-generated-secret' );

/* That's all, stop editing! Happy publishing. */
```

> مقدار `PWC_API_SECRET` باید دقیقاً با مقدار `API_SHARED_SECRET` در فایل `.env` سرور یکسان باشد. در هنگام کپی کردن، فاصله یا کاراکتر اضافی وارد نکنید.

## ۳. بررسی اتصال وردپرس به سرور

پس از ذخیره تغییرات `wp-config.php`:

1. وارد پیشخوان وردپرس شوید.
2. به بخش تنظیمات افزونه Persian AI Assistant بروید.
3. وضعیت اتصال به سرور را بررسی کنید.

در صورت تنظیم صحیح اطلاعات، وضعیت اتصال باید به شکل زیر نمایش داده شود:

**متصل (Connected)**

در این مرحله افزونه توانسته است با سرور هوش مصنوعی ارتباط برقرار کند.

## ۴. آموزش هوش مصنوعی با محتوای سایت

پس از برقراری اتصال، باید منابع اطلاعاتی سایت را در اختیار سیستم RAG قرار دهید.

از بخش مدیریت پایگاه دانش افزونه:

1. منابع محتوایی موردنظر را انتخاب کنید؛ مانند محصولات، نوشته‌ها و برگه‌ها.
2. محتوای موردنظر را استخراج و به پایگاه دانش اضافه کنید.
3. منتظر تکمیل پردازش و آماده‌سازی منابع بمانید.
4. وضعیت منابع پردازش‌شده را بررسی کنید.

در صورت استفاده از فایل‌های اختصاصی، می‌توانید آن‌ها را نیز از طریق بخش مدیریت منابع دانش بارگذاری کنید.

## ۵. فعال‌سازی چت‌بات

پس از آماده‌سازی پایگاه دانش:

1. به تنظیمات افزونه بروید.
2. ظاهر و تنظیمات ویجت چت را مطابق نیاز سایت شخصی‌سازی کنید.
3. قابلیت‌های موردنیاز مانند ارسال فایل و پیام صوتی را تنظیم کنید.
4. چت‌بات را فعال کنید.
5. سایت را باز کرده و نمایش ویجت چت را بررسی کنید.

اکنون بازدیدکنندگان می‌توانند از طریق ویجت چت با دستیار هوشمند سایت گفتگو کنند.

# بخش سوم: مدیریت سرور

تمام دستورات زیر باید در پوشه `ai-server` اجرا شوند:

```bash
cd /opt/ai-server
```

| عملیات | دستور |
|---|---|
| مشاهده وضعیت سرویس‌ها | `docker compose ps` |
| مشاهده لاگ تمام سرویس‌ها | `docker compose logs -f` |
| مشاهده لاگ API | `docker compose logs -f api` |
| راه‌اندازی مجدد سرویس‌ها | `docker compose restart` |
| توقف سرویس‌ها | `docker compose down` |
| اجرای مجدد و Build پروژه | `docker compose up -d --build` |
| مشاهده مصرف منابع | `docker stats` |

**نکته:** دستور `docker compose down` کانتینرها و شبکه‌های مربوط به Compose را متوقف و حذف می‌کند، اما Volumeهای نام‌گذاری‌شده را حذف نمی‌کند. برای حذف Volumeها از `-v` استفاده نکنید، مگر اینکه عمداً قصد حذف داده‌ها را داشته باشید.

## به‌روزرسانی سرور

در صورت جایگزینی یا دریافت نسخه جدید فایل‌های پروژه:

```bash
cd /opt/ai-server
```

سپس:

```bash
docker compose up -d --build
```

این دستور تصاویر موردنیاز را مجدداً Build کرده و سرویس‌ها را با نسخه جدید اجرا می‌کند.

# بخش چهارم: عیب‌یابی

### خطای `https_required` یا HTTP 400

آدرس سرور باید با پروتکل HTTPS و دامنه معتبر وارد شود.

صحیح:

```text
https://ai.example.com
```

نادرست:

```text
http://ai.example.com
http://SERVER_IP
```

### مشکل در صدور گواهی SSL

موارد زیر را بررسی کنید:

- رکورد DNS دامنه به IP صحیح سرور اشاره کند.
- پورت‌های 80 و 443 باز باشند.
- فایروال سرور یا ارائه‌دهنده VPS درخواست‌ها را مسدود نکرده باشد.
- دامنه از اینترنت قابل دسترسی باشد.

### خطای 401 هنگام اتصال افزونه

این خطا معمولاً به مشکل احراز هویت مربوط است.

مقادیر زیر را بررسی کنید:

```text
wp-config.php:
PWC_API_SECRET
```

```text
ai-server/.env:
API_SHARED_SECRET
```

این دو مقدار باید دقیقاً یکسان باشند.

### سرور اجرا نمی‌شود

وضعیت سرویس‌ها را بررسی کنید:

```bash
docker compose ps
```

سپس لاگ API را مشاهده کنید:

```bash
docker compose logs --tail=100 api
```

در صورت وجود خطای تنظیمات، پیام خطا معمولاً مشخص می‌کند کدام مقدار در فایل `.env` مشکل دارد.

### اتصال برقرار است اما چت‌بات پاسخ نمی‌دهد

موارد زیر را بررسی کنید:

- اتصال API به سرویس هوش مصنوعی و اعتبار API Key
- لاگ سرویس API
- آماده بودن منابع پایگاه دانش
- خطاهای درخواست‌های افزونه در پنل وردپرس
- در دسترس بودن REST API سایت

برای مشاهده لاگ زنده:

```bash
docker compose logs -f api
```

# نکات امنیتی

- فایل `.env` را در GitHub یا مخازن عمومی منتشر نکنید.
- کلید API هوش مصنوعی و `API_SHARED_SECRET` را در اختیار دیگران قرار ندهید.
- اطلاعات محرمانه را مستقیماً داخل فایل‌های اصلی پروژه قرار ندهید.
- ارتباط بین وردپرس و سرور را فقط از طریق HTTPS برقرار کنید.
- از اطلاعات و Volumeهای سرور به‌صورت منظم نسخه پشتیبان تهیه کنید.

# بررسی نهایی نصب

پس از اتمام مراحل، موارد زیر باید برقرار باشند:

- [ ] دامنه سرور به IP صحیح VPS متصل است.
- [ ] Docker و Docker Compose نصب شده‌اند.
- [ ] فایل `.env` با موفقیت ساخته شده است.
- [ ] تمام سرویس‌های Docker در وضعیت سالم اجرا می‌شوند.
- [ ] آدرس `/health` پاسخ `{"status":"ok"}` می‌دهد.
- [ ] افزونه روی وردپرس نصب و فعال شده است.
- [ ] مقادیر `PWC_API_URL` و `PWC_API_SECRET` در `wp-config.php` تنظیم شده‌اند.
- [ ] وضعیت اتصال افزونه به سرور «متصل» است.
- [ ] منابع دانش سایت با موفقیت پردازش شده‌اند.
- [ ] ویجت چت در سایت نمایش داده می‌شود.
- [ ] ارسال پیام و دریافت پاسخ از دستیار هوشمند با موفقیت انجام می‌شود.

**نصب با موفقیت انجام شد!** اکنون دستیار هوشمند آماده پاسخ‌گویی به بازدیدکنندگان وب‌سایت شماست.
