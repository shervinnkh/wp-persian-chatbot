<p align="center">
  An intelligent Persian chatbot for WordPress websites that uses Artificial Intelligence and the **Retrieval-Augmented Generation (RAG)** architecture to transform each website's own content into a searchable knowledge base, enabling it to answer visitors' questions based on the actual information available on that website.
</p>

By extracting and processing website content, incorporating custom files, and accessing live data such as product prices and discounts, the system creates an intelligent assistant tailored to each business. It can operate as an online website support agent, user guide, and customer inquiry assistant.

---

## Project Structure

This project consists of two independent components that work together seamlessly:

| Component | Path | Description |
|---|---|---|
| AI Server | `ai-server/` | AI backend, request processing, and RAG system management; ready for deployment on Linux servers using Docker. |
| WordPress Plugin | `wp-plugin/` | An installable WordPress plugin for managing the AI assistant, configuring settings, and communicating with the server. |

---

## Core Features

### 1. Chat Interface and User Interaction

- Adding an intelligent chat widget to WordPress websites.
- Real-time communication with the server through WebSocket and HTTP Polling.
- Support for sending and receiving structured messages generated by AI.
- Displaying relevant links and suggestions to guide users to different website pages.
- Support for sending voice messages, images, and files by users.
- AI-powered processing of voice messages and analysis of attached images and files.

### 2. Knowledge Base Management (RAG)

- Selecting different website content sources for information extraction, including products, posts, and pages.
- Automatic content extraction and cleaning of HTML and unnecessary data.
- Displaying the list of extracted content and allowing precise selection of the sources made available to the AI.
- Automatic knowledge base updates whenever website content is created, edited, or deleted.
- Uploading multiple files and adding their contents to the AI knowledge base.
- Managing knowledge sources through the plugin dashboard.

### 3. Access to Live Data

- Defining live data sources to provide AI with access to up-to-date website information.
- Retrieving product prices, discounts, and other dynamic product information.
- Preventing reliance on outdated information stored in the knowledge base when answering questions that require real-time data.

### 4. Management and Support

- Logging and monitoring system for tracking performance and investigating system errors.
- Automatic conversation flagging for escalation to human support whenever the AI cannot provide an appropriate answer.
- Managing and tracking conversations through the plugin dashboard.

### 5. Customization and Settings

- Full customization of the chat widget's appearance.
- Configuring color schemes, themes, and displayed text.
- Managing user file upload capabilities.
- Customizing the user experience to match the website's design and visual identity.

## Requirements

### WordPress Website

- WordPress version 6.0 or higher.
- PHP version 7.4 or higher.
- Required PHP extensions: `mbstring` and `dom`.
- Website accessible through the internet and using the `HTTPS` protocol.
- WordPress REST API enabled and its requests not blocked.
- WooCommerce installation (optional; required for accessing live product information, prices, and stock availability).

> **Note:** In the current version, the website must be hosted on a public domain accessible through the internet. Running the system on localhost is not supported.

### AI Server

- A Linux-based VPS.
- Docker and Docker Compose installed.
- A domain or subdomain pointing to the server's IP address.
- Ports 80 and 443 open for receiving requests and automatically issuing and renewing HTTPS certificates.
- An OpenAI API key or an API-compatible service.

---

## Communication Between Components

The WordPress plugin and the AI server communicate with each other through an API. Webhooks are also used for event exchange and notifications between the two components.

All sensitive requests must be protected using appropriate authentication and validation mechanisms.
