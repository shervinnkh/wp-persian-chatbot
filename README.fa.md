## ساختار پروژه

این پروژه از دو بخش مستقل تشکیل شده است که به صورت یکپارچه با یکدیگر ارتباط دارند:

| بخش | مسیر | توضیحات |
|---|---|---|
| سرور هوش مصنوعی | `ai-server/` | Backend هوش مصنوعی، پردازش درخواست ها و مدیریت سیستم RAG؛ آماده استقرار روی سرور لینوکس با Docker |
| افزونه وردپرس | `wp-plugin/` | افزونه قابل نصب روی وردپرس برای مدیریت دستیار هوشمند، تنظیمات و ارتباط با سرور |

## امکانات اصلی

### ۱. رابط کاربری و سیستم چت
- افزودن ویجت چت هوشمند به وبسایت وردپرسی
- ارتباط لحظه ای با سرور از طریق دو روش WebSocket و HTTP Polling
- پشتیبانی از ارسال و دریافت پیام های ساختار یافته توسط هوش مصنوعی
- نمایش لینک ها و پیشنهادهای مرتبط برای هدایت کاربران به صفحات مختلف سایت
- پشتیبانی از ارسال پیام صوتی، تصویر و فایل توسط کاربران
- قابلیت پردازش پیام های صوتی و بررسی محتوای تصاویر و فایل های پیوست شده توسط هوش مصنوعی

### ۲. مدیریت پایگاه دانش (RAG)
- انتخاب بخش های مختلف وبسایت برای استخراج اطلاعات، از جمله محصولات، نوشته ها و برگه ها
- استخراج خودکار محتوا و پاک سازی متن های HTML و داده های غیرضروری
- نمایش فهرست محتوای استخراج شده و امکان انتخاب دقیق منابعی که در اختیار هوش مصنوعی قرار می گیرند
- به روزرسانی خودکار پایگاه دانش هنگام ایجاد، ویرایش یا حذف محتوای وبسایت
- امکان بارگذاری فایل های متعدد و افزودن محتوای آن ها به منابع دانش هوش مصنوعی
- مدیریت منابع دانش از طریق پنل افزونه

### ۳. دسترسی به اطلاعات زنده (Live Data)
- تعریف منابع داده زنده برای دسترسی هوش مصنوعی به اطلاعات به روز وبسایت
- امکان استعلام قیمت، تخفیف و سایر اطلاعات متغیر محصولات
- جلوگیری از اتکا به اطلاعات قدیمی ذخیره شده در پایگاه دانش برای پاسخ به سوالات وابسته به داده های لحظه ای

### ۴. مدیریت و پشتیبانی
- سیستم ثبت لاگ و مانیتورینگ برای بررسی عملکرد و خطاهای سیستم
- امکان علامت گذاری خودکار گفتگوها برای ارجاع به پشتیبانی انسانی در صورت ناتوانی هوش مصنوعی در ارائه پاسخ مناسب
- مدیریت و پیگیری گفتگوها از طریق پنل افزونه

### ۵. شخصی سازی و تنظیمات
- شخصی سازی کامل ظاهر ویجت چت
- تنظیم رنگ بندی، تم و متن های نمایشی
- مدیریت قابلیت بارگذاری فایل توسط کاربران
- امکان تنظیم تجربه کاربری متناسب با طراحی و هویت بصری وبسایت

## پیش نیازها

### وبسایت وردپرسی

- WordPress نسخه 6.0 یا بالاتر
- PHP نسخه 7.4 یا بالاتر
- فعال بودن افزونه های PHP مورد نیاز: `mbstring` و `dom`
- در دسترس بودن وبسایت از طریق اینترنت و استفاده از پروتکل `HTTPS`
- فعال بودن REST API وردپرس و مسدود نبودن درخواست های آن
- نصب WooCommerce (اختیاری؛ برای دسترسی به اطلاعات محصولات و قیمت و موجودی زنده)

> توجه: در نسخه فعلی، وبسایت باید روی یک دامنه عمومی و قابل دسترس از اینترنت قرار داشته باشد. اجرای سیستم روی localhost پشتیبانی نمی شود.

### سرور هوش مصنوعی

- یک VPS لینوکسی
- نصب Docker و Docker Compose
- یک دامنه یا زیردامنه متصل به IP سرور
- باز بودن پورت های 80 و 443 برای دریافت و تمدید خودکار گواهی HTTPS
- کلید API سرویس OpenAI یا یک سرویس سازگار با API آن

## ارتباط بین اجزای سیستم

افزونه وردپرس و سرور هوش مصنوعی از طریق API با یکدیگر ارتباط برقرار می کنند. برای تبادل رویدادها و اطلاع رسانی بین دو بخش نیز از Webhook استفاده می شود.

تمام درخواست های حساس باید با مکانیزم های احراز هویت و اعتبارسنجی مناسب محافظت شوند.
